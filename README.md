# Student Task Manager (React)

A focused task manager for students to organize study, homework, exams, projects, and personal tasks.

## 🔧 Tech Stack

- React + Vite
- JavaScript, HTML, CSS
- LocalStorage for data persistence

## ✨ Features

- Add tasks with:
  - Title, subject / course
  - Category (Study, Homework, Exam, Project, Personal)
  - Priority (Low, Medium, High)
  - Due date
- Filter by status: All, Active, Completed
- Filter by category
- “Today’s focus” section showing the most important upcoming tasks
- Completion progress bar and basic stats
- Per-task notes for extra details
- Clean centered UI with navbar and footer

## 🚀 Getting Started

To run this project locally:

git clone https://github.com/akashkundu10/student-task-manager-react.git
cd student-task-manager-react/Task-Manager
npm install
npm run dev
